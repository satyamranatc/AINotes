1. LangChain & LCEL (`prompt | model | parser`)

In one line

LCEL (LangChain Expression Language) chains a Prompt Template, a Chat Model, and an Output Parser together using the Unix pipe operator (`|`) so the output of each step feeds cleanly into the next.

lcel_structured_output.py Python 
from pydantic import BaseModel, Field
from langchain_groq import ChatGroq
from langchain_core.prompts import ChatPromptTemplate

# 1. Define the strict output schema using Pydantic
class TicketTriage(BaseModel):
    category: str = Field(description="billing, technical, or account")
    urgent: bool = Field(description="True if production is blocked")

# 2. Build the prompt and bind structured output to the model
prompt = ChatPromptTemplate.from_messages([
    ("system", "Classify the customer support ticket."),
    ("human", "{ticket_text}")
])
llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0)

# 3. Pipe prompt into schema-bound model
chain = prompt | llm.with_structured_output(TicketTriage)
result = chain.invoke({"ticket_text": "Our production API key stopped working 5 mins ago!"})
print(result.category, "| Urgent:", result.urgent)
Protocol Function Calling

2. Tool Calling: The 4-Step Protocol Handshake

In one line

An LLM never runs your Python function directly—instead, it emits a structured JSON tool call request (`{"name": "get_weather", "args": {"city": "Delhi"}}`), your application runs the function locally, and you send the result back to the LLM.

Pillar 4: Agents ReAct Loop

3. Autonomous Agents: The ReAct Loop

In one line

While a simple chain runs a fixed set of steps once, an Autonomous Agent runs the LLM in a while loop—Thought → Action (Tool Call) → Observation (Tool Result)—deciding dynamically which tools to call and when the goal is complete.

Step-by-Step Code: Multi-Step ReAct Agent Loop

react_agent_loop.py Python 
from langchain_core.tools import tool
from langchain_core.messages import HumanMessage, ToolMessage
from langchain_groq import ChatGroq

@tool
def lookup_order_total(order_id: str) -> float:
    """Return the USD order total for an order ID."""
    return {"ORD-101": 250.0, "ORD-102": 80.0}.get(order_id, 0.0)

@tool
def calculate_refund_fee(amount: float) -> float:
    """Calculate the 5 percent restocking fee for a given USD amount."""
    return round(amount * 0.05, 2)

tools = {"lookup_order_total": lookup_order_total, "calculate_refund_fee": calculate_refund_fee}
llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0).bind_tools(list(tools.values()))

# Run the Autonomous Agent Loop (up to 5 reasoning steps)
messages = [HumanMessage(content="Find the total for ORD-101 and compute its restocking fee.")]
for step in range(5):
    ai_msg = llm.invoke(messages)
    messages.append(ai_msg)
    if not ai_msg.tool_calls:          # Goal reached -> exit loop!
        print("Agent Final Answer:", ai_msg.content)
        break
    for call in ai_msg.tool_calls:     # Execute requested tool & feed Observation back
        obs = tools[call["name"]].invoke(call["args"])
        print(f"Step {step+1} | Tool {call['name']}({call['args']}) -> {obs}")
        messages.append(ToolMessage(content=str(obs), tool_call_id=call["id"]))

What to notice: The agent automatically calls `lookup_order_total("ORD-101")` on Step 1, observes `250.0`, calls `calculate_refund_fee(250.0)` on Step 2, observes `12.5`, and then writes the final answer.

Pillar 5: MCP Universal Agent Standard

4. Model Context Protocol (MCP)

In one line

MCP (Model Context Protocol) is the "USB-C port for AI Agents": an open JSON-RPC 2.0 standard that lets any AI application (**Host/Client**) plug into any external tool or data source (**MCP Server**) without custom glue code.

5. Step-by-Step: Build a FastMCP Server & Client

Step 5A: The MCP Server (`server.py`)

server.py Python 
from mcp.server.fastmcp import FastMCP

# 1. Create the FastMCP server
mcp = FastMCP("Customer-DB-Server")

# 2. Register a read-only Resource
@mcp.resource("schema://customers")
def get_schema() -> str:
    """Return the SQL schema for the customers table."""
    return "CREATE TABLE customers (id INT PRIMARY KEY, name TEXT, tier TEXT);"

# 3. Register an executable Tool
@mcp.tool()
def get_customer_tier(customer_id: int) -> dict:
    """Look up a customer's tier and YTD spend by integer ID."""
    db = {101: {"name": "Acme Corp", "tier": "Enterprise", "spend_usd": 48500}}
    return db.get(customer_id, {"error": "Not found"})

if __name__ == "__main__":
    mcp.run(transport="stdio")

Step 5B: The MCP Client Agent (`client_agent.py`)

client_agent.py Python 
import asyncio
import json
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from groq import Groq

async def main():
    params = StdioServerParameters(command="python3", args=["server.py"])
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write) as session:
            # 1. Initialize handshake & discover tools from MCP Server
            await session.initialize()
            mcp_tools = (await session.list_tools()).tools
            llm_tools = [{
                "type": "function",
                "function": {"name": t.name, "description": t.description, "parameters": t.inputSchema}
            } for t in mcp_tools]

            # 2. Ask LLM using discovered MCP tools
            groq = Groq()
            messages = [{"role": "user", "content": "What tier is customer 101?"}]
            res = groq.chat.completions.create(
                model="llama-3.3-70b-versatile", messages=messages, tools=llm_tools
            )
            msg = res.choices[0].message

            # 3. Execute tool over MCP protocol & return final answer
            if msg.tool_calls:
                call = msg.tool_calls[0]
                out = await session.call_tool(call.function.name, json.loads(call.function.arguments))
                messages.append(msg)
                messages.append({"role": "tool", "tool_call_id": call.id, "content": out.content[0].text})
                final = groq.chat.completions.create(model="llama-3.3-70b-versatile", messages=messages)
                print(final.choices[0].message.content)

asyncio.run(main())
