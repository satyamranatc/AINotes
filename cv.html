1. Images as Tensors & Color Spaces (BGR vs. RGB vs. HSV)

In one line

To a computer, an image is just a 3D grid of numbers shaped $(\text{Height}, \text{Width}, \text{Channels})$ where each number ranges from $0$ (black) to $255$ (bright).

Color Space OpenCV Conversion Flag When to Use It
BGR / RGB cv2.COLOR_BGR2RGB Standard display, web images, and deep learning models.
Grayscale (1 channel) cv2.COLOR_BGR2GRAY Edge detection, thresholding, and barcode/document scanning ($3\times$ faster).
HSV (Hue, Saturation, Value) cv2.COLOR_BGR2HSV Color tracking under changing lighting (Hue isolates pure color regardless of shadows).

2. Spatial Filtering & 2D Convolution

In one line

A 2D Convolution slides a small grid of weights (a kernel, usually $3 \times 3$) across every pixel, multiplying overlapping numbers and adding them up to create a filtered output pixel.

3. Thresholding, Canny Edge Detection & Contours

  1. Gaussian Blur (cv2.GaussianBlur). Smooth out sensor speckle noise first so tiny speckles aren't mistaken for edges.
  2. Sobel Gradients. Measure horizontal ($G_x$) and vertical ($G_y$) brightness jumps at every pixel.
  3. Non-Maximum Suppression & Hysteresis (cv2.Canny). Thin wide blurry edges down to 1-pixel ridges and keep weak edges only if they touch strong edges.
  4. Find Contours (cv2.findContours). Link connected edge pixels into closed polygons so you can measure area, bounding boxes, and object counts.

4. Step-by-Step OpenCV Pipeline in Python

terminal Bash 
pip install opencv-python numpy
opencv_vision_pipeline.py Python 
import cv2
import numpy as np

# 1. Create a synthetic 200x200 image with a bright rectangle & circle
img = np.zeros((200, 200, 3), dtype=np.uint8)
cv2.rectangle(img, (30, 40), (110, 150), (255, 180, 50), -1)
cv2.circle(img, (155, 100), 30, (50, 220, 100), -1)

# 2. Convert BGR -> Grayscale and apply Gaussian Blur to remove noise
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blurred = cv2.GaussianBlur(gray, (5, 5), sigmaX=1.0)

# 3. Run Canny Edge Detection (low=50, high=150 threshold)
edges = cv2.Canny(blurred, threshold1=50, threshold2=150)

# 4. Find object contours and print bounding boxes
contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print(f"Detected {len(contours)} objects:")
for i, cnt in enumerate(contours, 1):
    x, y, w, h = cv2.boundingRect(cnt)
    print(f" - Object {i}: Box=(x={x}, y={y}, w={w}, h={h}), Area={cv2.contourArea(cnt):.0f}px")

What to notice: This exact 4-step sequence (`cvtColor` → `GaussianBlur` → `Canny` → `findContours`) is the workhorse of industrial inspection, document scanners, and robotics.

5. From Hand-Crafted Kernels to CNNs & Vision Transformers (ViT)

In classical OpenCV, a human engineer picks the $3 \times 3$ kernel numbers by hand (like the Sobel edge filter). In a Convolutional Neural Network (CNN), the network starts with random $3 \times 3$ kernels and learns the best filter numbers automatically via backpropagation!

6. Cheat Sheet

OpenCV Function What It Does
cv2.imread(path) Loads image as `(H, W, 3)` uint8 NumPy array in BGR order.
cv2.cvtColor(img, flag) Converts between BGR, RGB, Grayscale, and HSV.
cv2.GaussianBlur(img, (k,k), s) Smooths high-frequency noise using a Gaussian kernel.
cv2.Canny(gray, t1, t2) Extracts crisp 1-pixel-wide binary edges.
cv2.findContours(edges, ...) Finds closed object boundaries for area and bounding-box measurement.
