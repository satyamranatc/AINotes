Machine Learning Models: Principles, Mathematics, and Practical Selection

A comprehensive pedagogical study covering algorithmic mechanisms, mathematical formulations under the hood, and real-world trade-offs.

Author: Curriculum Research Group • Focus: Core Supervised Learning • Reading Time: 18 min

Machine learning models extract systematic empirical relationships from historical data to generalize over previously unobserved inputs. At its core, supervised machine learning partitions into two fundamental paradigms based on the nature of the target variable.

Problem Type Objective Canonical Examples
Regression Predict a continuous, numerical quantity Real estate valuation, employee compensation, temperature forecasting
Classification Predict a discrete class or qualitative label Spam detection, credit default risk, clinical diagnostics
Core Axiom

Regression answers "how much?" whereas classification answers "which category?"

Regression Parametric

1. Linear Regression

Primary Objective: Model and predict a continuous dependent variable as a linear combination of one or more input features.

Mechanics and Intuition

Consider estimating a student's academic marks ($Y$) given their weekly preparation hours ($X$). The algorithm models this interaction by identifying the optimal straight line traversing the feature space, adjusting its slope and intercept such that the aggregate discrepancy between real data points and the line is minimized.

Figure 1.1 Linear Regression: Fitted Model and Residual Errors

Mathematical Foundations

In simple univariate linear regression, the relationship is parameterized by:

$$\boxed{y = mx + b}$$
Variable Formal Definition Operational Context
$y$ Dependent target variable The predicted score or measurement
$x$ Independent predictor variable Observed input feature (e.g. study hours)
$m$ Weight / Slope parameter Rate of change in $y$ per unit change in $x$
$b$ Bias / Y-intercept parameter Baseline expected outcome when $x = 0$

Univariate Numerical Walkthrough: Given learned parameters $y = 10x + 20$, if a student dedicates $x = 5$ hours:

$$y = 10(5) + 20 = \boxed{70}$$

Multivariate Generalization: When extended to an arbitrary vector of $n$ features $(x_1, x_2, \dots, x_n)$:

$$\boxed{y = w_1x_1 + w_2x_2 + \dots + w_nx_n + b = \mathbf{w}^T\mathbf{x} + b}$$

Optimization Objective

Linear regression solves for the weights $\mathbf{w}$ that minimize the Mean Squared Error (MSE) across $n$ training instances:

$$\boxed{\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}\left(y_i - \hat{y}_i\right)^2}$$

Here, $y_i$ represents the verified ground truth, and $\hat{y}_i$ designates the model's computed estimation.

When to Use
  • Direct prediction of continuous numeric targets (e.g. pricing, sales volume, crop yield).
  • Relationships are known to be approximately linear.
  • Complete transparency and coefficient interpretability are essential.
  • Fast training and immediate analytical baselines are needed.
When to Avoid
  • Complex nonlinear interactions or polynomial geometries dominate.
  • Heavy uncleaned outliers exist that quadratically inflate MSE.
  • Severe multicollinearity among input features degrades coefficient stability.
Production Application

Predicting municipal property valuations by evaluating continuous features such as square footage, room count, and neighborhood desirability indices.

Classification Instance-Based / Non-Parametric

2. K-Nearest Neighbors (KNN)

Primary Objective: Classify an unobserved query instance by determining the consensus label among its $K$ most proximate neighbors in the feature space.

Mechanics and Intuition

Imagine receiving an unclassified fruit characterized by physical measurements (e.g. weight = 150g, color index = 0.85). The algorithm:

  1. Computes pairwise metric distances between the query instance and every indexed training sample.
  2. Sorts the records and isolates the $K$ points situated at minimal geometric distance.
  3. Tallies the discrete labels within this neighborhood.
  4. Assigns the plurality class (majority vote) to the query instance.
Figure 2.1 KNN Metric Neighborhood: K=1 versus K=5

Mathematical Foundations

Proximity is conventionally evaluated using Euclidean distance. For two planar points $\mathbf{x} = (x_1, y_1)$ and $\mathbf{z} = (x_2, y_2)$:

$$\boxed{d(\mathbf{x}, \mathbf{z}) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}}$$

Generalized across an $n$-dimensional attribute space $\mathbf{x}, \mathbf{z} \in \mathbb{R}^n$:

$$\boxed{d(\mathbf{x}, \mathbf{z}) = \sqrt{\sum_{j=1}^{n} (x_j - z_j)^2}}$$

Step-by-Step Calculation: Given coordinate vectors $A = (2, 3)$ and $B = (5, 7)$:

$$d = \sqrt{(5-2)^2 + (7-3)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \boxed{5}$$

The Hyperparameter Dilemma: Selecting $K$

Hyperparameter Setting Structural Effect on Boundary Bias-Variance Implication
$K = 1$ Highly jagged, complex decision boundaries matching every local outlier High Variance (Overfitting danger)
Small $K$ (e.g. 3) Retains sharp local flexibility while dampening individual noise points Balanced for dense clusters
Large $K$ (e.g. 50+) Overly smooth, generalized boundary dominated by global class distribution High Bias (Underfitting danger)
When to Use
  • Small to moderately sized datasets with low feature dimensionality.
  • Feature spaces where cluster proximity directly correlates with class membership.
  • No explicit functional training step is desired (instant ingestion).
When to Avoid
  • Large-scale production systems requiring low-latency scoring ($O(Nd)$ inference).
  • High-dimensional manifolds subject to the "Curse of Dimensionality".
  • Unnormalized datasets where differing feature scales distort metric distances.
Teacher's Note: The "Lazy Learner"

KNN executes zero iterative weight optimization during training ($O(1)$ training cost). It merely serializes the training corpus into memory. The entire computational overhead is deferred to inference time, when every query demands full-corpus distance evaluations.

Classification Regression (SVR) Max-Margin Boundary

3. Support Vector Machine (SVM)

Primary Objective: Construct an optimal separating hyperplane that maximizes the geometric margin between discrete classes.

Mechanics and Intuition

In linearly separable environments, an infinite number of potential hyperplanes can split two classes. SVM isolates the unique boundary that maximizes the clearance ("margin") separating itself from the closest instances of both classes. These critical boundary points are designated support vectors.

Figure 3.1 Maximum Margin Separating Hyperplane and Support Vectors

Mathematical Formulation

The linear decision boundary satisfies:

$$\boxed{\mathbf{w}^T\mathbf{x} + b = 0}$$

With binary decision function:

$$f(\mathbf{x}) = \text{sign}(\mathbf{w}^T\mathbf{x} + b)$$

The orthogonal distance from any arbitrary observation $\mathbf{x}$ to the hyperplane is:

$$\boxed{d = \frac{|\mathbf{w}^T\mathbf{x} + b|}{\|\mathbf{w}\|}}$$

For a linearly separable dataset bounded by canonical margins $\mathbf{w}^T\mathbf{x} + b = \pm 1$, total margin width equates to:

$$\boxed{\text{Margin Width} = \frac{2}{\|\mathbf{w}\|}}$$

Maximizing $\frac{2}{\|\mathbf{w}\|}$ is mathematically equivalent to solving the convex quadratic programming objective:

$$\boxed{\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{subject to } y_i(\mathbf{w}^T\mathbf{x}_i + b) \ge 1, \quad \forall i}$$

For real-world data with non-separable noise, a soft margin is implemented by incorporating slack variables $\xi_i \ge 0$ controlled by regularization penalty parameter $C$.

The Kernel Trick: Navigating Nonlinear Spaces

When data cannot be linearly partitioned in its original feature space $\mathbb{R}^d$, SVM applies a kernel function $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$ to compute inner products within a higher-dimensional implicit space without explicitly projecting coordinate vectors.

  • Linear Kernel: $K(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T\mathbf{z}$ (Ideal for text classification).
  • Polynomial Kernel: $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z} + c)^d$.
  • Radial Basis Function (RBF / Gaussian): $K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma \|\mathbf{x} - \mathbf{z}\|^2)$ (Excels at complex curvilinear envelopes).
When to Use
  • High-dimensional feature spaces where dimension count exceeds sample size ($d > n$).
  • Clear margin of separation exists between classes.
  • Text document classification, genome sequencing, and image recognition.
When to Avoid
  • Massive datasets containing hundreds of thousands to millions of rows ($O(n^2)$ to $O(n^3)$ training complexity).
  • Noisy data regimes with highly overlapping class distributions.
  • Use cases demanding direct probabilistic interpretation without Platt scaling calibration.
Core Distinguishing Fact

Unlike KNN, which evaluates all training records during every prediction, an SVM discards all non-boundary data post-training; the decision boundary relies exclusively on the support vectors.

Classification Probabilistic Linear Model

4. Logistic Regression

Primary Objective: Model the posterior conditional probability $P(Y=1|\mathbf{x})$ that an instance belongs to a target binary category.

Mechanics and Intuition

Despite the term "regression" in its name, Logistic Regression serves as a primary tool for discrete classification. Rather than outputting unbounded continuous values, the model computes an intermediate linear log-odds score and passes it through an activation function (the sigmoid) to squash outputs into the probability domain $(0, 1)$.

Figure 4.1 The Standard Logistic (Sigmoid) Function and Decision Boundary

Mathematical Foundations

Step 1: Compute the Linear Aggregate Score ($z$)

$$\boxed{z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b = \mathbf{w}^T\mathbf{x} + b}$$

Step 2: Map through the Logistic (Sigmoid) Function

$$\boxed{\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}}$$

Empirical Calculation Example: Suppose feature weighting yields $z = 2$ for a candidate:

$$P(Y = \text{Pass}) = \frac{1}{1 + e^{-2}} \approx \frac{1}{1 + 0.1353} = \boxed{0.881} \quad (88.1\%)$$

Subject to standard decision threshold $\tau = 0.5$:

  • If $P \ge 0.5 \implies$ Predict Pass (Class 1)
  • If $P < 0.5 \implies$ Predict Fail (Class 0)

Loss Function: Binary Cross-Entropy (Log Loss)

Because the sigmoid function renders Mean Squared Error non-convex, parameter estimation applies Maximum Likelihood Estimation via Binary Cross-Entropy Loss:

$$\boxed{L(\mathbf{w}) = -\frac{1}{n}\sum_{i=1}^{n}\Big[y_i \ln(p_i) + (1 - y_i)\ln(1 - p_i)\Big]}$$

Where $y_i \in \{0, 1\}$ represents ground truth, and $p_i = \sigma(\mathbf{w}^T\mathbf{x}_i + b)$ denotes predicted probability.

When to Use
  • Direct probabilistic risk estimates (e.g. loan default probability, customer churn likelihood).
  • Highly interpretable feature odds ratios ($e^{w_j}$) are required.
  • Standard classification baseline for tabular and sparse textual datasets.
When to Avoid
  • Strongly nonlinear decision boundaries without explicit feature transformations.
  • Complex high-order feature interactions that are unmodeled in the feature engineering stage.
Production Application

Subscriber churn prediction: Estimating probability that a recurring SaaS account will terminate service within 30 days based on login frequency, ticket volume, and billing tier.

Classification Regression (CART) Rule-Based / Non-Parametric

5. Decision Tree

Primary Objective: Partition the input feature space recursively into orthogonal hyper-rectangles using hierarchical, rule-based splits that maximize information gain.

Mechanics and Intuition

A decision tree operates like an expert decision flowchart. Starting at the root node containing the entire dataset, the algorithm evaluates every candidate feature and split threshold, selecting the split that maximally purifies the resulting child subsets.

Figure 5.1 Hierarchical Decision Tree Flow and Node Partitioning

Mathematical Foundations: Splitting Criteria

1. Gini Impurity (CART Default)

Measures the frequency with which a randomly selected element from the subset would be incorrectly labeled if classified according to the label distribution:

$$\boxed{\text{Gini} = 1 - \sum_{i=1}^{C} p_i^2}$$

Example 1: Perfectly Balanced Node (50% Pass, 50% Fail)

$$\text{Gini} = 1 - \left(0.5^2 + 0.5^2\right) = 1 - (0.25 + 0.25) = \boxed{0.50} \quad (\text{Maximum Impurity})$$

Example 2: Pure Node (100% Pass)

$$\text{Gini} = 1 - (1.0^2) = \boxed{0.0} \quad (\text{Perfect Purity})$$

2. Shannon Entropy (ID3 / C4.5)

Measures the expected information content or uncertainty present in a set of outcomes:

$$\boxed{H(S) = -\sum_{i=1}^{C} p_i \log_2(p_i)}$$

For a node with 50% Pass and 50% Fail:

$$H = -\left[0.5 \log_2(0.5) + 0.5 \log_2(0.5)\right] = -[0.5(-1) + 0.5(-1)] = \boxed{1.0\text{ bit}}$$

For a pure single-class node: $H = 0\text{ bits}$.

3. Information Gain (Reduction in Uncertainty)

$$\boxed{\text{IG}(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)}$$

The tree systematically selects the feature $A$ and threshold that maximize Information Gain (or maximize Gini reduction).

When to Use
  • Strict auditing and explainability demands (e.g. credit underwriting, diagnostic pathways).
  • Mixed feature types (numerical and categorical) without mandatory feature scaling.
  • Rapid non-linear modeling and feature importance inspection.
When to Avoid
  • High variance regimes where slight training data shifts alter tree topology drastically.
  • Linear or additive relationships requiring deep stair-step approximations.
  • Unconstrained depth settings leading to acute memorization/overfitting.
Teacher's Tip: Regularization Hyperparameters

To prevent unconstrained tree expansion from memorizing noise, constrain growth using: max_depth (terminal tree height), min_samples_split (minimum instances required to branch), and min_samples_leaf (minimum quota per terminal leaf).

Ensemble Architecture Classification Regression

6. Random Forest

Primary Objective: Construct an ensemble of decorrelated decision trees to substantially reduce prediction variance while preserving low model bias.

Mechanics and Intuition

A single decision tree is prone to high variance: slight variations in the training sample generate completely different splits. Random Forest implements the Wisdom of Crowds by training hundreds of individual trees, each observing perturbed data and feature subsets, before aggregating their outputs into a consensus prediction.

Figure 6.1 Random Forest Architecture: Bagging, Feature Subsampling, and Aggregation

Mathematical Foundations

Random Forest relies on two complementary randomization pillars:

  1. Bootstrap Aggregation (Bagging): Each tree $T_m$ is trained on an independently drawn bootstrap subset of $N$ records sampled with replacement from the parent training set. Typically, each bootstrap sample captures approximately $(1 - 1/e) \approx 63.2\%$ of unique instances; the unselected $36.8\%$ form the Out-Of-Bag (OOB) evaluation pool.
  2. Random Feature Subsampling: At every candidate split within each tree, only a random subset of features is evaluated (typically $m = \sqrt{p}$ for classification, and $m = p/3$ for regression). This prevents dominant predictors from inducing strong cross-tree correlation.

Ensemble Combination Formulations

Classification via Plurality (Majority) Voting:

$$\boxed{\hat{y} = \operatorname{mode}\Big\{T_1(\mathbf{x}),\, T_2(\mathbf{x}),\, \dots,\, T_M(\mathbf{x})\Big\}}$$
Tree Instance Individual Predicted Class Ensemble Aggregation Tally
Tree 1, 2, 4 Pass Pass: 3 votes • Fail: 2 votes
Consensus Prediction: Pass
Tree 3, 5 Fail

Regression via Output Averaging:

$$\boxed{\hat{y} = \frac{1}{M}\sum_{m=1}^{M} T_m(\mathbf{x})}$$

For house price estimates across three trees ($₹40\text{L}, ₹45\text{L}, ₹50\text{L}$):

$$\hat{y} = \frac{40 + 45 + 50}{3} = \boxed{₹45\text{ lakh}}$$
When to Use
  • Top-tier benchmark performance on structured, tabular datasets.
  • Presence of complex high-order feature interactions and non-linear boundaries.
  • Mitigating extreme overfitting inherent in single decision trees.
When to Avoid
  • Ultra-low latency microsecond scoring constraints.
  • Severe compute/memory hardware boundaries on edge devices.
  • Extrapolating targets beyond observed training ranges in regression tasks.
Production Application

Financial transaction fraud scoring: Evaluating historical telemetry, merchant attributes, device fingerprints, and geolocation anomalies in high-throughput banking channels.

Part 6: Comparative Analysis of Loss & Splitting Metrics

Students frequently conflate objective functions, loss penalties, and metric distances. The table below delineates their specific operational domains.

Metric / Formula Primary Algorithm Domain Physical / Mathematical Meaning
Mean Squared Error (MSE) Linear Regression & Regression Trees Average squared Euclidean deviation between continuous observations and predictions
Gini Impurity Decision Trees (CART) Probability of misclassifying a randomly chosen element under subset label distribution
Entropy (Shannon) Decision Trees (ID3 / C4.5) Quantitative measure of informational disorder, surprise, or uncertainty in bits
Information Gain Decision Trees Net reduction in parent node entropy achieved by applying a candidate split
Binary Cross-Entropy Loss Logistic Regression & Classifiers Kullback-Leibler divergence measuring penalty for confident erroneous probability assignments
Euclidean Distance K-Nearest Neighbors Straight-line metric distance separating coordinate vectors across $d$-dimensional space
Geometric Margin ($2/\|\mathbf{w}\|$) Support Vector Machine Orthogonal clearance corridor separating opposing class support vectors

Architectural Distinction Summary

  • Linear Regression seeks to minimize continuous numeric prediction deviations.
  • Logistic Regression seeks to minimize classification probability divergence.
  • Decision Trees seek partition thresholds that maximally cleanse impurity.
  • KNN queries geometric proximity without learning parametric coefficients.
  • SVM optimizes the geometric clearance corridor separating classes.
  • Random Forest averages out individual model variance across diverse randomized trees.

Part 8: Three Fundamental Concepts to Teach Students

1. Feature Scaling and Metric Sensitivity

Numerical features frequently inhabit wildly disparate physical scales. For instance, consider modeling individuals where Age spans $[18, 65]$ years while Annual Salary spans $[₹10,000, ₹2,000,000]$.

Without normalization or standardization ($z = \frac{x - \mu}{\sigma}$), the salary feature numerically dominates distance metrics by four orders of magnitude, rendering the age feature inconsequential.

Algorithm Class Requires Feature Scaling? Underlying Cause
KNN Strictly Mandatory Metric distance directly distorts along larger axes
SVM Strictly Mandatory Gradient steps and margin regularizer $\|\mathbf{w}\|^2$ penalize coordinates unevenly
Logistic / Linear (Regularized) Mandatory $L_1$ and $L_2$ penalties unfairly compress coefficients of smaller-scale features
Decision Tree & Random Forest Not Required Splits evaluate rank-order monotonicity along single features independently

2. The Bias-Variance Tradeoff: Underfitting vs. Overfitting

The central challenge in supervised learning is ensuring that the empirical model generalizes effectively to unseen distributions rather than memorizing stochastic noise.

Figure 7.1 The Bias-Variance Spectrum: Underfitting, Generalization, and Overfitting

3. Training Phase versus Inference Workflow

Every supervised pipeline partitions cleanly into four discrete lifecycle phases:

  1. Data Partitioning: Strictly segment historical records into training, validation, and untouched test partitions before feature preprocessing.
  2. Parameter Estimation (Training): The algorithm optimizes its weights ($\mathbf{w}, b$) or establishes orthogonal boundary rules to minimize training loss.
  3. Hyperparameter Tuning (Validation): Calibrate structural constraints (such as $K$ in KNN, $C$ and $\gamma$ in SVM, or max_depth in Trees) on cross-validation sets.
  4. Generalization Assessment (Inference): Evaluate final model fidelity on the pristine test holdout to obtain an unbiased estimate of real-world production performance.

Executive Revision: Algorithmic Synopses

Model Architecture Concise One-Line Theoretical Definition
Linear Regression Determines a hyperplane parameterizing an approximately linear mapping to predict continuous quantities.
K-Nearest Neighbors (KNN) Assigns classification or continuous estimates via local distance weighting among nearest stored training records.
Support Vector Machine (SVM) Solves a quadratic programming objective to isolate a separating boundary that maximizes orthogonal margin clearance.
Logistic Regression Passes a linear combination of input features through a sigmoid activation to model class posterior probabilities.
Decision Tree Partitions feature space via a hierarchical sequence of orthogonal questions to maximize purity at terminal leaves.
Random Forest Aggregates an ensemble of decorrelated bootstrap trees via voting or averaging to neutralize individual tree variance.
The Core Pedagogical Principle

Do not teach students only the mathematical formulas. Teach them which specific problem each formula was invented to solve.

When students grasp that Gini Impurity and Shannon Entropy serve as scoring functions for feature split quality, that Euclidean distance quantifies point similarity, and that the $2/\|\mathbf{w}\|$ margin objective creates an error-tolerance cushion, the mathematics transitions from arbitrary rote equations into intuitive, purposeful engineering.
