Building Block Artificial Neuron

1. The Single Neuron (Perceptron)

In one line

An artificial neuron takes several numeric inputs, multiplies each by a weight, adds a bias, and passes the total through an activation function.

Think of it like this

Deciding whether to go to a concert works like a neuron: you weigh factors like ticket price ($w_1 = -3$), favorite band ($w_2 = +5$), and rain forecast ($w_3 = -2$), add your general love of live music (bias $b$), and if the total score clears your personal threshold, you fire ("Go!").

How It Works

  1. Weight each input. Multiply every input feature $x_j$ by its learned connection weight $w_j$.
  2. Sum and shift. Add all weighted inputs together plus a bias term $b$ to get the pre-activation score $z$.
  3. Activate. Pass $z$ through a non-linear function $f(z)$ (like ReLU or Sigmoid) to produce the neuron's output $a$.

The Math in Plain Words

$$\boxed{a = f\left(\sum_{j=1}^{n} w_j x_j + b\right) = f(\mathbf{w}^T\mathbf{x} + b)}$$

Worked Example: Given inputs $\mathbf{x} = [2, 3]$, weights $\mathbf{w} = [0.5, -1.0]$, bias $b = 4$, and activation $\text{ReLU}(z) = \max(0, z)$:

$$z = (0.5)(2) + (-1.0)(3) + 4 = 1 - 3 + 4 = 2 \implies a = \max(0, 2) = 2$$
Core Architecture MLP / Dense Network

2. Feedforward Neural Network (FNN / MLP)

In one line

A Feedforward Neural Network (FNN)—also called a Multi-Layer Perceptron (MLP)—arranges neurons into successive layers where information flows strictly forward from input to output, with no loops.

Think of it like this

Think of an assembly line in a factory: Station 1 (Input Layer) receives raw parts; Station 2 (Hidden Layer 1) combines parts into sub-assemblies; Station 3 (Hidden Layer 2) combines sub-assemblies into major modules; and Station 4 (Output Layer) produces the finished decision.

How It Works

  1. Input Layer ($\mathbf{x}$). Holds your raw features (one node per column, e.g. age, income, pixel brightness).
  2. Hidden Layers ($\mathbf{h}^{(1)}, \mathbf{h}^{(2)}, \dots$). Each neuron in a hidden layer receives outputs from every neuron in the previous layer (which is why PyTorch calls it a Linear or fully connected / dense layer).
  3. Layer-by-layer matrix step. Each hidden layer computes $\mathbf{h}^{(l)} = f(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)})$.
  4. Output Layer ($\hat{\mathbf{y}}$). Produces the final prediction (1 node for regression or binary classification; $C$ nodes with Softmax for $C$-class classification).
Universal Approximation Theorem
A foundational theorem proving that an FNN with even a single sufficiently wide hidden layer and non-linear activations can approximate any continuous function.
Width vs. Depth
Width is the number of neurons in a layer; Depth is the number of stacked layers.
Non-Linearity

3. Activation Functions: Why Linear Layers Alone Fail

In one line

Without a non-linear activation function between layers, a 100-layer neural network collapses mathematically into a single flat Linear Regression layer.

Why? Because multiplying two matrices in a row is still just one matrix: $\mathbf{W}_2(\mathbf{W}_1\mathbf{x}) = (\mathbf{W}_2\mathbf{W}_1)\mathbf{x} = \mathbf{W}_{\text{combined}}\mathbf{x}$. Activation functions bend the space between layers so the network can learn curves, corners, and complex logic (like XOR).

Activation Formula Where to Use It
ReLU $\max(0, z)$ Default choice for hidden layers in FNNs and CNNs. Fast and prevents vanishing gradients for $z > 0$.
GELU / SwiGLU $z \cdot \Phi(z)$ Hidden layers of Transformers and LLMs (smooth curve around zero).
Sigmoid $1 / (1 + e^{-z})$ Output layer for binary classification (outputs a single probability in $(0,1)$).
Softmax $e^{z_i} / \sum_j e^{z_j}$ Output layer for multi-class classification (turns $C$ scores into probabilities that sum to $1.0$).
Learning Engine Chain Rule

4. Forward Pass & Backpropagation

In one line

The Forward Pass computes the prediction and loss; Backpropagation works backward from the loss using the calculus Chain Rule to tell every weight in every layer how much it contributed to the error.

The Chain Rule in One Equation

If input $x$ produces $z = wx$, which produces activation $a = f(z)$, which produces loss $L(a, y)$, then the sensitivity of the loss to weight $w$ is simply the product of three local derivatives:

$$\boxed{\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}}$$

In words: (how much the loss changes when output $a$ changes) $\times$ (slope of the activation function) $\times$ (the input $x$).

5. Optimizers, Dropout & Batch Normalization

Three practical ingredients make deep FNNs train reliably without memorizing noise:

Technique What Problem It Solves How It Works
Adam Optimizer Plain Gradient Descent oscillates or gets stuck in ravines Tracks both momentum (rolling average of gradients) and adaptive per-weight step sizes.
Dropout Neurons co-adapt and memorize the training data Randomly zeroes out a fraction $p$ (e.g. $20\%$) of hidden neurons on each training batch so the network learns redundant pathways.
BatchNorm / LayerNorm Activations explode or vanish across deep layers Re-centers and scales activations inside each layer to mean $0$ and variance $1$.
Spatial Deep Learning Convolutional Neural Networks (CNN)

6. Convolutional Neural Networks (CNN) Explained Simply Step-by-Step

In one line

A Convolutional Neural Network (CNN) is a neural network built for images and grid data that slides small learnable filters (kernels) across a 2D picture to detect edges, textures, parts, and whole objects—without flattening the image first.

Why Not Just Use a Standard FNN on Images?

Suppose you feed a standard $224 \times 224$ color photo ($224 \times 224 \times 3 = 150,528$ pixel values) into a regular Feedforward Neural Network (FNN). Two serious problems happen immediately:

  1. Flattening destroys 2D spatial structure. An FNN requires a flat 1D vector of numbers. Unrolling a 2D grid into a single long line throws away the crucial fact that pixel $(10, 10)$ sits right above pixel $(11, 10)$ to form an edge or an eye.
  2. Parameter explosion & instant overfitting. If your very first hidden layer has just $1,000$ neurons, connecting all $150,528$ pixels to $1,000$ neurons requires $150,528 \times 1,000 = \mathbf{150.5\text{ million weights}}$ in a single layer! And if the cat in the photo shifts two pixels to the right, the FNN has to re-learn those weights from scratch.
Think of it like this: The Sliding Flashlight

Imagine looking for a cat on a mural in a dark room. Instead of trying to photograph every square inch at once with $150\text{ million}$ separate sensors (an FNN), you shine a small $3 \times 3$ flashlight beam (a filter) and slide it across the wall row by row. One flashlight detector only lights up when it sees a vertical edge; another lights up on pointed ears; a third lights up on whiskers. Because the exact same $3 \times 3$ detector slides over the entire picture (parameter sharing), it only needs $9$ weights to find a vertical edge anywhere in the image—top-left, center, or bottom-right!

How a CNN Works in 5 Simple Steps

  1. Step 1 — Convolution (Conv2D): Slide a small filter and multiply-and-add. Take a small $3 \times 3$ grid of learnable weights called a filter (or kernel). Place it on the top-left $3 \times 3$ patch of the image, multiply each filter weight by the overlapping pixel underneath it, sum all $9$ products, and add a bias $b$. Write that single total into a new grid called a Feature Map, then slide the filter 1 pixel over and repeat.
  2. Step 2 — Activation (ReLU): Keep only positive pattern matches. Pass every number in the feature map through $\text{ReLU}(z) = \max(0, z)$. Negative numbers (where the pattern did not match) become $0$, while positive numbers (where the edge or texture strongly matched) stay bright.
  3. Step 3 — Pooling (MaxPooling2D): Shrink the map by keeping the strongest signal. Slide a $2 \times 2$ window across the feature map with a step size (stride) of $2$, and keep only the single largest number in each $2 \times 2$ box. This cuts the height and width in half (reducing data size by $75\%$) and makes the network translation-invariant—if an edge shifts by 1 pixel inside that $2 \times 2$ box, the maximum value stays the same.
  4. Step 4 — Stack Conv + Pool Blocks to build a hierarchy of vision. Repeat `Conv2D -> ReLU -> MaxPool2D` two or three times:
    • Layer 1 learns simple horizontal, vertical, and diagonal edges.
    • Layer 2 combines edges into corners, circles, stripes, and textures.
    • Layer 3 combines textures into object parts (eyes, wheels, bird beaks).
  5. Step 5 — Flatten & Classify (Flatten → Dense → Softmax). Once the feature maps are small and rich in high-level meaning (for example, $5 \times 5 \times 64$), unroll them into a 1D vector (`Flatten`) and pass them into a small FNN (`Dense` layer + `Softmax`) to output final class probabilities.

The 4 Knobs of Every Conv2D Layer

1. Filters / Kernels ($F$)
How many distinct pattern detectors the layer learns in parallel (typically $32$, $64$, or $128$). Each filter produces its own 2D slice, so $F$ becomes the number of output channels.
2. Kernel Size ($K \times K$)
The height and width of the sliding window—almost universally $3 \times 3$ in modern CNNs. Two stacked $3 \times 3$ layers see the same $5 \times 5$ neighborhood with fewer weights and an extra non-linear ReLU in between.
3. Padding ($P$)
padding='valid' ($P=0$) uses no border, so a $3 \times 3$ filter shrinks height and width by $2$ pixels (`28 -> 26`). padding='same' ($P=1$ for a $3 \times 3$ kernel) pads a 1-pixel ring of zeros around the image so the output height and width stay identical (`28 -> 28`).
4. Stride ($S$)
How many pixels the filter jumps after each step. $S=1$ scans every single position; $S=2$ skips every other pixel, cutting the output height and width in half.

The Formula: How Spatial Shapes Change Across Layers

$$H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} - K + 2P}{S} \right\rfloor + 1, \qquad \text{Params}_{\text{Conv2D}} = \big(K \times K \times C_{\text{in}} + 1\big) \times F$$

Worked Example with Real Numbers: Let's trace a grayscale digit image of shape $(28, 28, 1)$ ($H_{\text{in}}=28, W_{\text{in}}=28, C_{\text{in}}=1$) through our first block:

  • Pass through Conv2D(filters=32, kernel_size=3, padding='valid', strides=1):
    • Output height/width: $H_{\text{out}} = \lfloor \frac{28 - 3 + 2(0)}{1} \rfloor + 1 = \mathbf{26}$.
    • Output tensor shape: (26, 26, 32).
    • Trainable parameters: $(3 \times 3 \times 1 + 1\text{ bias}) \times 32 = 10 \times 32 = \mathbf{320\text{ parameters}}$! (An FNN connecting $28 \times 28 = 784$ inputs to $32$ neurons would need $784 \times 32 + 32 = 25,120$ parameters—nearly $80\times$ more).
  • Pass through MaxPooling2D(pool_size=2, strides=2):
    • Output height/width: $H_{\text{out}} = \lfloor \frac{26 - 2}{2} \rfloor + 1 = \mathbf{13}$.
    • Output tensor shape: (13, 13, 32) with $0$ trainable parameters (pooling just picks the maximum value in each $2 \times 2$ square).
Deep Learning Framework TensorFlow 2.x & tf.keras

7. TensorFlow & tf.keras Explained Simply

In one line

TensorFlow is Google's industrial deep learning engine that runs tensor math on CPUs, GPUs, and TPUs, while tf.keras is its clean high-level API that lets you assemble, compile, and train neural networks in just a few lines of Python.

The 4 Core Building Blocks of TensorFlow

1. tf.Tensor (Multi-Dimensional Arrays on Accelerators)
Just like a NumPy array, a tf.Tensor holds a grid of numbers (e.g., shape (64, 28, 28, 1) for a batch of 64 images), except TensorFlow can automatically move it onto a GPU or TPU and track derivatives through every math operation.
2. tf.keras.Sequential (The Straight-Line LEGO Stack)
When your neural network flows in a single line from Input → Hidden Layers → Output (which covers $90\%$ of FNNs and standard CNNs), tf.keras.Sequential([...]) lets you pass a simple Python list of layers.
3. The tf.keras Functional API (Multi-Branch & Residual Graphs)
When you need multiple inputs (e.g., an image + tabular metadata) or skip connections like ResNet (out = layers.Add()([x, shortcut])), you call layers like Python functions: x = layers.Dense(64, activation='relu')(inputs).
4. tf.GradientTape (Automatic Differentiation Recorder)
Under the hood of model.fit(), TensorFlow uses a context manager called with tf.GradientTape() as tape: to record every forward-pass operation on a "tape" and then play the tape backward via tape.gradient(loss, model.trainable_variables) to compute exact gradients.

Which TensorFlow Output Layer & Loss Function Should You Pick?

One of the most common beginner bugs in TensorFlow is mismatching the final Dense layer and the loss function in model.compile(). Use this exact lookup table:

Task Type Target Label Format y Final layers.Dense Layer TensorFlow Loss in model.compile()
Regression (Predict a price/score) Continuous float (e.g., 245.5) Dense(1) (no activation) 'mse' or tf.keras.losses.MeanSquaredError()
Binary Classification (2 classes) 0 or 1 Dense(1, activation='sigmoid') 'binary_crossentropy'
Multi-Class (Integer IDs) Integer class ID: 0, 1, ..., 9 Dense(10, activation='softmax') 'sparse_categorical_crossentropy'
Multi-Class (One-Hot Vectors) One-hot array: [0, 0, 1, 0] Dense(4, activation='softmax') 'categorical_crossentropy'

8. Step-by-Step: How to Build an FNN and a CNN in TensorFlow

Below are two complete, runnable TensorFlow 2.x scripts: first a Feedforward Neural Network (FNN), and second a Convolutional Neural Network (CNN). Compare them side by side to see how a CNN replaces the upfront Flatten + huge Dense layer with spatial Conv2D and MaxPooling2D blocks.

Part A: How to Make a Feedforward Neural Network (FNN / MLP) in TensorFlow

To build an FNN in TensorFlow, we stack layers.Dense blocks with activation='relu', add BatchNormalization and Dropout so the network generalizes well, and finish with a Dense output layer.

fnn_tensorflow_keras.py Python 
import tensorflow as tf
from tensorflow.keras import layers, models, callbacks

# 1. Load & normalize dataset (MNIST 28x28 grayscale digits: 0 to 9)
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()
X_train = X_train.astype("float32") / 255.0   # Scale pixels from [0, 255] -> [0.0, 1.0]
X_test  = X_test.astype("float32") / 255.0

# 2. Define the Feedforward Neural Network (FNN / MLP)
fnn_model = models.Sequential([
    layers.Input(shape=(28, 28)),             # Input: 28x28 grid
    layers.Flatten(),                         # Unroll 28x28 -> 784 flat features (1D vector)
    
    # Hidden Layer 1: 128 neurons + BatchNorm + ReLU + Dropout
    layers.Dense(128, activation="relu"),     # 784 * 128 + 128 = 100,480 parameters
    layers.BatchNormalization(),
    layers.Dropout(0.2),                      # Randomly drop 20% of neurons during training
    
    # Hidden Layer 2: 64 neurons + ReLU
    layers.Dense(64, activation="relu"),      # 128 * 64 + 64 = 8,256 parameters
    
    # Output Layer: 10 classes (digits 0-9) with Softmax probabilities
    layers.Dense(10, activation="softmax")    # 64 * 10 + 10 = 650 parameters
], name="Feedforward_FNN")

fnn_model.summary()

# 3. Compile the FNN (Optimizer + Loss + Evaluation Metric)
fnn_model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss="sparse_categorical_crossentropy",   # Use 'sparse_' because y_train has integer IDs (0..9)
    metrics=["accuracy"]
)

# 4. Train with EarlyStopping so we automatically stop if validation loss stops improving
early_stop = callbacks.EarlyStopping(
    monitor="val_loss", patience=3, restore_best_weights=True
)

history = fnn_model.fit(
    X_train, y_train,
    epochs=10,
    batch_size=64,
    validation_split=0.1,
    callbacks=[early_stop]
)

# 5. Evaluate on unseen test set
test_loss, test_acc = fnn_model.evaluate(X_test, y_test, verbose=0)
print(f"FNN Test Accuracy: {test_acc:.4f} | Test Loss: {test_loss:.4f}")

Part B: How to Make a Convolutional Neural Network (CNN) in TensorFlow

Notice the difference below: instead of flattening the image at the start, a CNN keeps the 3D image shape (Height, Width, Channels) = (28, 28, 1) and passes it through two Conv2D → BatchNormalization → MaxPooling2D blocks before flattening at the very end.

cnn_tensorflow_keras.py Python 
import tensorflow as tf
from tensorflow.keras import layers, models

# 1. Load & reshape images to 4D tensor: (Batch, Height, Width, Channels)
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()
X_train = (X_train.astype("float32") / 255.0)[..., tf.newaxis]  # Shape: (60000, 28, 28, 1)
X_test  = (X_test.astype("float32") / 255.0)[..., tf.newaxis]   # Shape: (10000, 28, 28, 1)

# 2. Define the Convolutional Neural Network (CNN) Step-by-Step
cnn_model = models.Sequential([
    layers.Input(shape=(28, 28, 1)),                            # Tensor: (28, 28, 1)

    # --- CONV BLOCK 1: Learn 32 low-level edge filters ---
    layers.Conv2D(filters=32, kernel_size=(3, 3),
                  padding="valid", activation="relu"),          # Tensor: (26, 26, 32) | 320 params
    layers.BatchNormalization(),
    layers.MaxPooling2D(pool_size=(2, 2)),                      # Tensor: (13, 13, 32) | Halves H & W

    # --- CONV BLOCK 2: Learn 64 mid-level shape/part filters ---
    layers.Conv2D(filters=64, kernel_size=(3, 3),
                  padding="valid", activation="relu"),          # Tensor: (11, 11, 64) | 18,496 params
    layers.BatchNormalization(),
    layers.MaxPooling2D(pool_size=(2, 2)),                      # Tensor: (5, 5, 64)   | Halves H & W

    # --- CLASSIFIER HEAD: Flatten 3D maps -> FNN Dense layers ---
    layers.Flatten(),                                           # Tensor: (1600,) because 5*5*64 = 1600
    layers.Dense(128, activation="relu"),                       # Tensor: (128,)
    layers.Dropout(0.3),                                        # Prevent overfitting in the Dense head
    layers.Dense(10, activation="softmax")                      # Tensor: (10,) probabilities
], name="Vision_CNN")

cnn_model.summary()

# 3. Compile & Train the CNN
cnn_model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

cnn_model.fit(X_train, y_train, epochs=5, batch_size=64, validation_split=0.1)

# 4. Evaluate & Predict on a single image
test_loss, test_acc = cnn_model.evaluate(X_test, y_test, verbose=0)
print(f"CNN Test Accuracy: {test_acc:.4f}")

# Predict class for the first test image
probs = cnn_model.predict(X_test[:1], verbose=0)                # Shape: (1, 10)
predicted_digit = int(tf.argmax(probs[0]))
print(f"Predicted Digit: {predicted_digit} (Confidence: {probs[0][predicted_digit]:.2%})")
Deep Dive: Writing a Custom Training Loop in TensorFlow with tf.GradientTape

While model.fit() handles $95\%$ of standard training jobs, research models (like GANs, Reinforcement Learning, or custom physics losses) need explicit control over every gradient step. TensorFlow gives you that with tf.GradientTape and @tf.function (which JIT-compiles Python into a fast C++/XLA computation graph):

custom_gradient_tape_loop.py Python 
import tensorflow as tf

loss_fn = tf.keras.losses.SparseCategoricalCrossentropy()
optimizer = tf.keras.optimizers.Adam(learning_rate=1e-3)

@tf.function  # Compiles this function into a high-speed TensorFlow graph
def train_step(x_batch: tf.Tensor, y_batch: tf.Tensor) -> tf.Tensor:
    # 1. Record all forward-pass operations on the GradientTape
    with tf.GradientTape() as tape:
        probs = cnn_model(x_batch, training=True)
        loss = loss_fn(y_batch, probs)

    # 2. Compute gradients d(loss)/d(weights) automatically
     grads = tape.gradient(loss, cnn_model.trainable_variables)

    # 3. Update weights using the optimizer
    optimizer.apply_gradients(zip(grads, cnn_model.trainable_variables))
    return loss

9. Step-by-Step: Build & Train an FNN in PyTorch

To compare TensorFlow with PyTorch: where TensorFlow's model.fit() automates the loop (or uses tf.GradientTape), every PyTorch training loop writes the 5-step rhythm explicitly: Forward pass → Compute loss → Zero old gradients → Backpropagate → Optimizer step.

terminal Bash 
pip install torch
fnn_pytorch_quickstart.py Python 
import torch
import torch.nn as nn

# 1. Define a 3-layer Feedforward Neural Network (FNN / MLP)
class SimpleFNN(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, num_classes: int):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(p=0.2),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)  # Raw logits out
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)

# 2. Create synthetic data (128 samples, 10 features, 3 classes)
X = torch.randn(128, 10)
y = torch.randint(0, 3, (128,))

model = SimpleFNN(input_dim=10, hidden_dim=32, num_classes=3)
criterion = nn.CrossEntropyLoss()  # Applies Softmax + Log Loss internally
optimizer = torch.optim.Adam(model.parameters(), lr=1e-2)

# 3. The 5-Step Training Loop
for epoch in range(1, 51):
    logits = model(X)               # Step 1: Forward pass
    loss = criterion(logits, y)     # Step 2: Compute loss
    optimizer.zero_grad()           # Step 3: Clear old gradients
    loss.backward()                 # Step 4: Backpropagation (Chain Rule)
    optimizer.step()                # Step 5: Update weights

    if epoch % 10 == 0:
        print(f"Epoch {epoch:02d} | Loss: {loss.item():.4f}")

What to notice: We do not put a `Softmax` layer at the end of `SimpleFNN` because PyTorch's `nn.CrossEntropyLoss()` combines `LogSoftmax` and negative log-likelihood in one numerically stable step.

10. FNN, CNN & TensorFlow Cheat Sheet

Component / Layer TensorFlow (tf.keras) What It Does & Why You Need It
Fully Connected Layer (FNN) layers.Dense(128, activation='relu') Connects every input feature to every neuron; standard building block for tabular data and classifier heads.
2D Convolution (CNN) layers.Conv2D(32, (3, 3), activation='relu') Slides $32$ learnable $3 \times 3$ filters across a 2D image to detect local spatial features (edges, textures, parts).
Spatial Downsampling layers.MaxPooling2D(pool_size=(2, 2)) Keeps the maximum value in each $2 \times 2$ patch, cutting height & width in half and adding translation invariance.
Bridge 3D Maps → 1D Vector layers.Flatten() Unrolls 3D feature maps $(H, W, C)$ into a flat 1D vector so final Dense layers can classify the image.
Regularization & Stability BatchNormalization() + Dropout(0.2) Normalizes internal layer activations and randomly drops $20\%$ of neurons during training to stop overfitting.
Multi-Class Loss (Integer IDs) loss='sparse_categorical_crossentropy' Computes cross-entropy loss directly against integer class labels (0, 1, ..., C-1) without needing one-hot encoding.
