Building Block Artificial Neuron

1. The Single Neuron (Perceptron)

In one line

An artificial neuron takes several numeric inputs, multiplies each by a weight, adds a bias, and passes the total through an activation function.

Think of it like this

Deciding whether to go to a concert works like a neuron: you weigh factors like ticket price ($w_1 = -3$), favorite band ($w_2 = +5$), and rain forecast ($w_3 = -2$), add your general love of live music (bias $b$), and if the total score clears your personal threshold, you fire ("Go!").

How It Works

  1. Weight each input. Multiply every input feature $x_j$ by its learned connection weight $w_j$.
  2. Sum and shift. Add all weighted inputs together plus a bias term $b$ to get the pre-activation score $z$.
  3. Activate. Pass $z$ through a non-linear function $f(z)$ (like ReLU or Sigmoid) to produce the neuron's output $a$.

The Math in Plain Words

$$\boxed{a = f\left(\sum_{j=1}^{n} w_j x_j + b\right) = f(\mathbf{w}^T\mathbf{x} + b)}$$

Worked Example: Given inputs $\mathbf{x} = [2, 3]$, weights $\mathbf{w} = [0.5, -1.0]$, bias $b = 4$, and activation $\text{ReLU}(z) = \max(0, z)$:

$$z = (0.5)(2) + (-1.0)(3) + 4 = 1 - 3 + 4 = 2 \implies a = \max(0, 2) = 2$$
Core Architecture MLP / Dense Network

2. Feedforward Neural Network (FNN / MLP)

In one line

A Feedforward Neural Network (FNN)—also called a Multi-Layer Perceptron (MLP)—arranges neurons into successive layers where information flows strictly forward from input to output, with no loops.

Think of it like this

Think of an assembly line in a factory: Station 1 (Input Layer) receives raw parts; Station 2 (Hidden Layer 1) combines parts into sub-assemblies; Station 3 (Hidden Layer 2) combines sub-assemblies into major modules; and Station 4 (Output Layer) produces the finished decision.

How It Works

  1. Input Layer ($\mathbf{x}$). Holds your raw features (one node per column, e.g. age, income, pixel brightness).
  2. Hidden Layers ($\mathbf{h}^{(1)}, \mathbf{h}^{(2)}, \dots$). Each neuron in a hidden layer receives outputs from every neuron in the previous layer (which is why PyTorch calls it a Linear or fully connected / dense layer).
  3. Layer-by-layer matrix step. Each hidden layer computes $\mathbf{h}^{(l)} = f(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)})$.
  4. Output Layer ($\hat{\mathbf{y}}$). Produces the final prediction (1 node for regression or binary classification; $C$ nodes with Softmax for $C$-class classification).
Universal Approximation Theorem
A foundational theorem proving that an FNN with even a single sufficiently wide hidden layer and non-linear activations can approximate any continuous function.
Width vs. Depth
Width is the number of neurons in a layer; Depth is the number of stacked layers.
Non-Linearity

3. Activation Functions: Why Linear Layers Alone Fail

In one line

Without a non-linear activation function between layers, a 100-layer neural network collapses mathematically into a single flat Linear Regression layer.

Why? Because multiplying two matrices in a row is still just one matrix: $\mathbf{W}_2(\mathbf{W}_1\mathbf{x}) = (\mathbf{W}_2\mathbf{W}_1)\mathbf{x} = \mathbf{W}_{\text{combined}}\mathbf{x}$. Activation functions bend the space between layers so the network can learn curves, corners, and complex logic (like XOR).

Activation Formula Where to Use It
ReLU $\max(0, z)$ Default choice for hidden layers in FNNs and CNNs. Fast and prevents vanishing gradients for $z > 0$.
GELU / SwiGLU $z \cdot \Phi(z)$ Hidden layers of Transformers and LLMs (smooth curve around zero).
Sigmoid $1 / (1 + e^{-z})$ Output layer for binary classification (outputs a single probability in $(0,1)$).
Softmax $e^{z_i} / \sum_j e^{z_j}$ Output layer for multi-class classification (turns $C$ scores into probabilities that sum to $1.0$).
Learning Engine Chain Rule

4. Forward Pass & Backpropagation

In one line

The Forward Pass computes the prediction and loss; Backpropagation works backward from the loss using the calculus Chain Rule to tell every weight in every layer how much it contributed to the error.

The Chain Rule in One Equation

If input $x$ produces $z = wx$, which produces activation $a = f(z)$, which produces loss $L(a, y)$, then the sensitivity of the loss to weight $w$ is simply the product of three local derivatives:

$$\boxed{\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w}}$$

In words: (how much the loss changes when output $a$ changes) $\times$ (slope of the activation function) $\times$ (the input $x$).

5. Optimizers, Dropout & Batch Normalization

Three practical ingredients make deep FNNs train reliably without memorizing noise:

Technique What Problem It Solves How It Works
Adam Optimizer Plain Gradient Descent oscillates or gets stuck in ravines Tracks both momentum (rolling average of gradients) and adaptive per-weight step sizes.
Dropout Neurons co-adapt and memorize the training data Randomly zeroes out a fraction $p$ (e.g. $20\%$) of hidden neurons on each training batch so the network learns redundant pathways.
BatchNorm / LayerNorm Activations explode or vanish across deep layers Re-centers and scales activations inside each layer to mean $0$ and variance $1$.

6. Step-by-Step: Build & Train an FNN in PyTorch

Every PyTorch training loop follows the exact same 5-step rhythm inside the loop: Forward pass → Compute loss → Zero old gradients → Backpropagate → Optimizer step.

terminal Bash 
pip install torch
fnn_pytorch_quickstart.py Python 
import torch
import torch.nn as nn

# 1. Define a 3-layer Feedforward Neural Network (FNN / MLP)
class SimpleFNN(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, num_classes: int):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(p=0.2),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)  # Raw logits out
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)

# 2. Create synthetic data (128 samples, 10 features, 3 classes)
X = torch.randn(128, 10)
y = torch.randint(0, 3, (128,))

model = SimpleFNN(input_dim=10, hidden_dim=32, num_classes=3)
criterion = nn.CrossEntropyLoss()  # Applies Softmax + Log Loss internally
optimizer = torch.optim.Adam(model.parameters(), lr=1e-2)

# 3. The 5-Step Training Loop
for epoch in range(1, 51):
    logits = model(X)               # Step 1: Forward pass
    loss = criterion(logits, y)     # Step 2: Compute loss
    optimizer.zero_grad()           # Step 3: Clear old gradients
    loss.backward()                 # Step 4: Backpropagation (Chain Rule)
    optimizer.step()                # Step 5: Update weights

    if epoch % 10 == 0:
        print(f"Epoch {epoch:02d} | Loss: {loss.item():.4f}")

What to notice: We do not put a `Softmax` layer at the end of `SimpleFNN` because PyTorch's `nn.CrossEntropyLoss()` combines `LogSoftmax` and negative log-likelihood in one numerically stable step.

7. Cheat Sheet

Component Standard Choice Why
Hidden Activation ReLU or GELU Prevents vanishing gradients and is fast to compute.
Output Layer (Regression) Linear (1 node) + MSE Loss Allows any unbounded real number as output.
Output Layer (Binary Class) 1 node + `BCEWithLogitsLoss` Outputs calibrated probability for Class 1.
Output Layer (Multi-Class) $C$ nodes + `CrossEntropyLoss` Produces probability distribution across $C$ classes.
Optimizer Adam / AdamW (`lr=1e-3`) Adapts step sizes per weight automatically.
